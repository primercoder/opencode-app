# OC Remote 1.0.6

此版本基于 GitHub Issues #1–#10 的反馈完善手机端会话体验、OpenCode 状态同步、断线恢复和任务控制，并修复主机/中继服务配置及管理问题。

## 主要更新

- 保持流式会话更新连贯，修复历史消息同步缺口和重连后的状态恢复。
- 修复中继房间重连时临时满员导致连接无法恢复的问题。
- 完善会话停止、后台 Shell/Job 任务展示与取消操作。
- 改进手机端目录选择、配对流程、滚动定位和状态提示。
- 修复主机端端口切换、服务配置持久化和中继管理命令问题。
- 补充 Docker、弱网、Android 模拟器和 OpenCode API 使用说明。

## 版本与构建

- 手机、主机和中继版本：1.0.6
- Android versionCode：19（ABI APK 按架构生成对应升级码）
- Android APK 使用仓库的 Expo debug keystore 签名。

## 验证

- Bun 测试、TypeScript 检查和 Go 中继测试通过。
- Android API 35 x86_64 模拟器验证会话流式输出、前后台恢复、中继断线重连、任务停止、文件查看和 Diff 页面。
- Docker 中继 + Toxiproxy 弱网测试通过；下行 220 ± 30 毫秒、96 KB/s，断线期间新增的 75 条消息在重连后完整恢复。

## 下载

Android arm64 APK 用于常见手机和平板；x86_64 APK 用于模拟器。Linux 主机包自带 Bun 和语音运行库。Linux 中继包提供 amd64 和 arm64 二进制。
