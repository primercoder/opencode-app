安装与配对

应该下载哪个 APK？

真机和平板使用 android-arm64-v8a.apk；x86_64 模拟器使用 android-x86_64.apk。装错架构通常会在安装阶段报 ABI 不匹配。

手机提示连接失败，但电脑上 opencode 正在运行。

先先在主机执行 ./ocremote direct 0.0.0.0:8787，再运行 ./ocremote pair；只有回环地址不会生成手机直连二维码。再检查电脑防火墙是否允许 TCP 8787，手机是否在同一网络。

配对码过期了怎么办？

在电脑上运行 ./ocremote pair 生成新码，然后在手机上重新添加主机。配对码默认 5 分钟过期；终端里可以用 --ttl 调整。

为什么手机上显示的主机指纹要和电脑核对？

指纹对应主机的 Noise 静态公钥。逐段核对可以避免连接到伪造主机；指纹不一致时不要继续配对。

会话与命令

手机端支持哪些斜杠命令？

核心命令包括 /models、/agents、/mcps、/skills、/variants、/sessions、/new、/compact、/status、/diff 和 /help。/init、/review、/goal 等服务端命令会继续发给 opencode。

为什么有些命令是灰色的？

它们依赖终端、编辑器、worktree 或桌面能力，手机端不会执行。置灰是为了明确不可用，而不是发送请求后返回 404。

运行中发消息会怎样？

消息会进入队列，当前任务结束后自动发送。输入框上方可以看到排队数量，也可以取消排队项。

其他终端改了 Agent 或模型，手机需要刷新吗？

不需要。手机会通过事件流刷新当前会话，状态栏和设置面板会自动更新；其他端也能收到手机发起的变更事件。

中继认证与可选 TLS

中继是必须的吗？

不是。同一局域网优先直连；中继用于手机和电脑不在同一网络、或者需要穿透 NAT 的场景。中继只转发加密帧。

中继认证失败怎么办？

确认中继地址可达、主机执行过 ./ocremote relay 或指定了正确的 IP:端口，并且中继没有达到 --max-hosts。中继升级或数据库重置后需要重新登记。

还可以使用 TLS 吗？

可以。TLS 是可选传输层，Noise NK 认证和加密控制帧不依赖它。使用公共 CA 时不需要额外配置；只有自签 wss:// 才需要给主机传 --relay-ca，并在 Android 系统信任库安装 CA。

中继能看到我的代码吗？

看不到应用数据。中继能看到房间、subject 身份、连接时间和帧大小等元数据，但会话、文件和工具内容都在 Noise 密文里。

Release 与构建

为什么 APK 用 debug keystore？

当前发布包仍使用 Expo debug keystore 签名，便于测试安装。正式分发前需要替换生产 keystore，并重新生成 Release。

主机端有 arm64 包吗？

有。ocremote-host-0.1.6-linux-arm64.tar.gz 内置 arm64 Bun 和 sherpa-onnx；x64 主机使用对应的 linux-x64 包。

怎么校验下载文件？

从 Release 下载 SHA256SUMS，和构建产物放在同一目录，执行 sha256sum -c SHA256SUMS。
