SECURITY MODEL

A relay can forward.
It cannot read.

Phone and host always speak Noise NK end-to-end. Direct mode adds only a replaceable transport. Relay mode forwards application data as ciphertext and exposes the routing metadata it needs.

01 / DATA PATH

Who sees what.

opencode stays bound to 127.0.0.1. The host reads local service registration and keeps the opencode password; the phone never receives it.

02 / PAIRING

It starts with a one-time code.

The pairing code hands the host identity and transport routes to the phone. A device token is used for later authentication; the host never stores the plaintext token.

See pairing steps →
01

Host creates a pair code

It carries the host Noise static public key, fingerprint, a single-use code and transport routes. Codes expire after five minutes by default.

02

Phone checks the fingerprint

The phone displays the host fingerprint. Compare it with the computer output to avoid joining an impersonated host.

03

Host returns a device token

The host stores only a hash and the device scope. The phone stores the token in Android SecureStore.

04

Each connection handshakes again

X25519 ephemeral keys complete Noise NK. OCRP control frames and proxied payloads then travel inside protected records.

03 / KEYS

Where the keys live. Where the boundary ends.

This model protects application data between phone and host. It does not defend a computer that is already compromised, nor does it hide routing metadata from the relay.

The relay can still observe who connects, when, room size and traffic patterns. Noise protects application payloads, not metadata anonymity.

04 / RELEASE

Release and QA stay separate.

Release and QA APKs use different application ids and certificate policies. Release trusts only the Android system CA store.

BuildApplication idTLS trust
Releaseapp.ocremote.androidAndroid system CA store
QAapp.ocremote.android.qasystem CA + development test CA

The test CA is development-only. To use a self-signed relay with the Release APK, install that CA in the Android system store or use a certificate from a public CA.
