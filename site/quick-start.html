QUICK START · 0.1.6

三步连上你的 opencode。

主机端和 opencode 跑在同一台电脑；手机负责操作；中继端只有跨网络时才需要。下面所有命令都以 Linux x64 为例，arm64 替换文件名即可。

先确认三件事

opencode 2.x 已经在电脑上运行；手机和电脑在同一局域网，或者你准备一台中继；安装的 APK 架构和手机匹配。

下载最新 Release ↗
中继不是必需品。同一局域网内优先使用直连，少一层网络，少一个要维护的服务。
01

启动主机端

解压主机包，运行开始命令。主机端会读取本机 opencode 服务注册信息，opencode 密码不会离开电脑。

HOST · LINUX X64
tar xzf ocremote-host-0.1.6-linux-x64.tar.gz
cd ocremote
./ocremote start
./ocremote direct 0.0.0.0:8787
./ocremote pair

arm64 主机包使用 ocremote-host-0.1.6-linux-arm64.tar.gz。默认后台运行，管理命令是 ./ocremote status、clients、stop。

02

安装手机端并配对

真机安装 android-arm64-v8a.apk，x86_64 模拟器安装 android-x86_64.apk。打开 App，点 +，扫描主机二维码或粘贴配对链接。

ANDROID
adb install ocremote-0.1.6-android-arm64-v8a.apk

连接前核对手机上显示的主机指纹。配对码一次性有效，默认 5 分钟过期；配对成功后设备令牌保存在 Android SecureStore。

03

需要跨网络时，再加中继

中继端是 Go 静态二进制，只转发加密帧。内置 Noise NK 认证，启动时不需要额外证书；中继启动不生成 host link；主机只需地址和端口。执行 ./ocremote relay 默认连接 118.31.124.193:8443，手机会通过配对码自动登记中继。

RELAY · OPTIONAL
./ocremote-relay --data-dir ./data \
  --listen 0.0.0.0:8443 \
  --public-url ws://<公网IP>:8443/ws

在主机端登记中继：

HOST · RELAY ENROLL
./ocremote relay
./ocremote pair

Noise NK 会用 /v1/info 获取并固定的中继公钥，认证和控制帧都在加密通道里。TLS 仍是可选层：启用 wss:// 时可以用公共 CA，或把自签 CA 安装到 Android 系统信任库。

连接需要的最小信息。

主机端默认只监听本机；手机要直连时至少把监听地址改成 0.0.0.0 或指定网卡，并允许防火墙放行 TCP 8787。

项目默认值说明
直连端口8787手机与主机在同一局域网时使用
中继端口8443Noise NK 认证；TLS 可选
主机配置~/.config/ocremote/identity.json、config.json，权限 0600
中继数据./data/relay.db、relay-identity.json、admin.sock；可选 tls/
语音模型~/.local/share/ocremote/models/主机 SenseVoice；手机 Whisper 单独下载
